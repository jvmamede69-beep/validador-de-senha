# Validador de Senha

Projeto simples em Python que verifica se uma senha é forte e explica o que está faltando quando ela é fraca. Inclui testes automatizados com pytest.

## Regras

- Mínimo de 8 caracteres
- Pelo menos uma letra minúscula e uma maiúscula
- Pelo menos um número
- Pelo menos um caractere especial
- Sem espaços

## Como usar

```bash
python senha.py
```

Digite uma senha e o programa mostra se ela é forte ou quais regras não foram atendidas.

## Rodando os testes

```bash
pip install pytest
pytest
```

## Tecnologias

Python 3.9+ e pytest.
